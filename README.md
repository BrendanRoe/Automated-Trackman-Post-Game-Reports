# Automated-Trackman-Post-Game-Reports
   This is a project that I created in Python that has the ability to read Trackman CSVs and produce reports on each individual pitcher in the game. These reports allow coaches and analysts to review metrics and overall success with pitchers after their outings, leading to a standardized system for performance review. 
   To generate the code I worked in VS Code while writing in Python with the use of AI-coding assistance. My project is separated into 5 separate files each correlating to a section of the final pdf that is generated. This project is easy to use and can be utilized as soon as CSV files are distributed from Trackman following a game. You simply drop in the CSV, select the game that you want to analyze, and the system generates a folder containing individual PDFs of the players that appeared in the game.
